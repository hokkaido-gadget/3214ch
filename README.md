# みついしどっとこむ リニューアル案

公開ページ: https://hokkaido-gadget.github.io/3214ch/

現サイト https://3214ch.com/ の店舗紹介と店舗サイトマップを照合した14店舗・事業所のデザイン案です。旧URL porto は porto-mitsuishi に転送されるため重複を除外しています。三石商店会の名簿とは対象範囲が異なります。

- index.html: 店舗一覧・カテゴリーと商品キーワード検索
- shops/: 各店舗の独立した紹介ページ14件
- assets/shops/: 元サイトの各店舗に対応する写真38枚のWebP
- shops-data.js: 店舗データ
- photo-sources.json: 店舗と写真取得元の対応・確認情報

GitHub Pagesはmainブランチのルートを公開します。ビルドは不要です。写真原本は作業PCにも別途保存しています。営業情報は掲載元に基づき、店舗への直接確認は未実施です。写真内の料金・メニューや商品の販売状況は撮影当時の内容です。
